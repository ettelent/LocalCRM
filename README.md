# NEXUS CRM

CRM для двух пользователей: клиенты → проекты → задачи → чек-листы и обсуждения. Также доступны общий реестр задач, глобальный поиск и график оплат.

Проект использует единую архитектуру:

- Vue 3 + Vite — клиент;
- Express — API;
- MySQL 8.4 — база данных;
- Docker Compose — запуск всех сервисов;
- phpMyAdmin — управление базой.

## Запуск

Создайте `.env` на основе примера и замените персональные ключи:

```bash
copy .env.example .env
docker compose up -d --build
```

То же действие доступно через `npm start`. Остальные корневые команды (`npm run build`, `npm run stop`, `npm run logs`) также управляют Docker Compose и не создают альтернативного локального контура.

После запуска доступны:

- CRM: `http://localhost:8080`;
- API: `http://localhost:3000`;
- phpMyAdmin: `http://localhost:8081`;
- MySQL: `localhost:3306`.

Просмотр состояния и журналов:

```bash
docker compose ps
docker compose logs -f
```

Остановка контейнеров без удаления данных:

```bash
docker compose down
```

Данные MySQL хранятся в именованном volume `mysql_data` и сохраняются после перезапуска контейнеров. Для Linux-сервера предусмотрен `deploy.sh`.

## Основные возможности

- канбан клиентов по стадиям;
- проекты и задачи клиентов;
- общий реестр задач с фильтрами;
- исполнитель, приоритет и крайний срок задачи;
- чек-листы и обсуждения;
- глобальный поиск по клиентам, проектам, задачам и сообщениям;
- график оплат со статусами, фактической датой, способом оплаты и сводными суммами.

## API

Все маршруты, кроме входа, требуют заголовок `Authorization: Bearer <key>`.

- `POST /api/auth/login` — вход по персональному ключу;
- `/api/clients` — CRUD клиентов и стадии канбана;
- `/api/projects` — CRUD проектов, фильтр `?clientId=`;
- `/api/tasks` — CRUD задач и расширенные поля;
- `/api/tasks/:id/todos` — чек-лист задачи;
- `/api/tasks/:id/messages` — обсуждение задачи;
- `/api/payment-schedules` — график и статусы оплат;
- `GET /api/search?q=` — глобальный поиск.

Удаление клиента каскадно удаляет его проекты и связанные данные; удаление проекта — его задачи.
